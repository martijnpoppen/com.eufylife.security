OBSOLETA — pásate a «Anker Eufy»

Esta app ha dejado de desarrollarse. La sustituye Anker Eufy, que admite las mismas cámaras,
videoporteros, HomeBases, cerraduras, teclados y sensores, y también los robots aspiradores que
necesitaban Eufy Clean.

  https://homey.app/a/com.eufy/

Anker Eufy inicia sesión con su propia identidad de dispositivo, así que ya no necesitas una segunda
cuenta «admin» y no cerrará la sesión de tu móvil en la app de eufy.

Cómo cambiar: instala Anker Eufy, añade ahí tus dispositivos, rehaz tus Flows y elimina esta app
cuando estés conforme. Mientras tanto ambas pueden convivir. Esta app sigue funcionando, pero no
recibirá dispositivos ni funciones nuevas.


Instrucciones de instalación

Debido a la forma en que funciona la API privada de Eufy Security, una combinación de correo electrónico/contraseña no puede funcionar tanto con la aplicación móvil de Eufy Security como con la aplicación de Homey.

Se recomienda usar la aplicación móvil de Eufy para crear una cuenta "admin" secundaria con una dirección de correo electrónico diferente y usarla con esta aplicación.

Uso
- Instala esta aplicación en tu Homey.
- Ve a `añadir dispositivos`
- Proporciona tu Nombre de Usuario y Contraseña. Haz clic en Siguiente
- Los dispositivos disponibles aparecerán
