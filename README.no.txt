UTDATERT — gå over til «Anker Eufy»

Denne appen utvikles ikke lenger. Den er erstattet av Anker Eufy, som støtter de samme kameraene,
dørklokkene, HomeBase-ene, låsene, tastaturene og sensorene — og robotstøvsugerne som før krevde
Eufy Clean.

  https://homey.app/a/com.eufy/

Anker Eufy logger inn med sin egen enhetsidentitet, så du trenger ikke lenger en ekstra
«admin»-konto, og telefonen din blir ikke logget ut av eufy-appen.

Slik flytter du over: installer Anker Eufy, legg til enhetene dine der, bygg opp Flow-ene på nytt og
fjern denne appen når du er fornøyd. Begge appene kan kjøre side om side i mellomtiden. Denne appen
virker fortsatt, men får ikke nye enheter eller funksjoner.


Installering instruksjoner 

På grunn av måten Eufy Security private API fungerer, kan en e-post/passord kombinasjon ikke fungere både med Eufy Security mobilapp og Homey appen. 

Det anbefales å bruke mobilappen til Eufy for å lage en sekundær "admin" konto med en separat e-postadresse og bruke den med denne appen.

Bruk
- Installer denne appen på din Homey.
- Gå til `legg til enheter`
- Oppgi ditt brukernavn og passord. Klikk Neste
- Tilgjengelige enheter vises
