DEPRECATED — please move to "Anker Eufy"

This app is no longer being developed. It is replaced by Anker Eufy, which supports the same
cameras, video doorbells, HomeBases, locks, keypads and sensors, and the robot vacuums that used to
need Eufy Clean — all in one app.

  https://homey.app/a/com.eufy/

Anker Eufy also removes the biggest annoyance of this app: it signs in with its own device identity,
so you no longer need a second "admin" eufy account and it will not sign your phone out of the eufy
mobile app.

How to move across:
- Install Anker Eufy from the Homey App Store.
- Add your devices there. A Homey device belongs to the app that created it, so the devices have to
  be paired again and the Flows that used them rebuilt.
- Remove this app once you are happy. Both apps can run side by side until then, so you can move one
  device at a time.

This app still works and will keep working while you move. It will not receive new devices or new
features.


Install instructions (this app)

Because of the way the Eufy Security private API works, an email/password combo cannot
work with both the Eufy Security mobile app and the Homey app.

It is recommended to use the mobile Eufy app to create a secondary "admin" account with a separate email address
and use it with this app.

Usage
- Install this app on your Homey.
- Go to `add devices`
- Provide your Username and Password. Click Next
- Available devices show up
