OBSOLÈTE — passez à « Anker Eufy »

Cette application n'est plus développée. Elle est remplacée par Anker Eufy, qui prend en charge les
mêmes caméras, sonnettes, HomeBases, serrures, claviers et capteurs, ainsi que les aspirateurs robots
qui nécessitaient Eufy Clean.

  https://homey.app/a/com.eufy/

Anker Eufy se connecte avec sa propre identité d'appareil : vous n'avez plus besoin d'un second
compte « admin », et votre téléphone ne sera pas déconnecté de l'application eufy.

Pour migrer : installez Anker Eufy, ajoutez-y vos appareils, reconstruisez vos Flows, puis supprimez
cette application quand tout vous convient. Les deux peuvent coexister entre-temps. Cette application
continue de fonctionner, mais ne recevra ni nouveaux appareils ni nouvelles fonctionnalités.


Instructions d'installation (français)

En raison du fonctionnement de l'API privée d'Eufy Security, un ensemble e-mail/mot de passe ne peut pas
fonctionner à la fois avec l'application mobile Eufy Security et l'application Homey.

Il est recommandé d'utiliser l'application mobile Eufy pour créer un compte "admin" secondaire avec une adresse e-mail distincte
et de l'utiliser avec cette application.

Utilisation :
- Installez cette application sur votre Homey.
- Accédez à "Ajouter des appareils"
- Sélectionner Eufy Security
- Indiquez votre nom d'utilisateur et votre mot de passe. Cliquez sur Suivant
- Les appareils disponibles s'affichent
