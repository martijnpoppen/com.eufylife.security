지원 종료 — ‘Anker Eufy’로 옮겨 주세요

이 앱은 더 이상 개발되지 않습니다. 후속 앱인 Anker Eufy가 같은 카메라, 비디오 초인종, HomeBase,
도어락, 키패드, 센서는 물론 Eufy Clean이 필요했던 로봇청소기까지 지원합니다.

  https://homey.app/a/com.eufy/

Anker Eufy는 자체 기기 식별자로 로그인하므로 별도의 ‘관리자’ 계정이 필요 없고, 휴대폰의 eufy 앱
로그인도 풀리지 않습니다.

옮기는 방법: Anker Eufy를 설치하고 기기를 추가한 뒤 Flow를 다시 만들고, 만족스러우면 이 앱을
삭제하세요. 그동안 두 앱을 함께 사용할 수 있습니다. 이 앱은 계속 작동하지만 새 기기나 새 기능은
추가되지 않습니다.


설치 안내

Eufy Security의 비공개 API 작동 방식 때문에, 동일한 이메일/비밀번호 조합을 Eufy Security 모바일 앱과 Homey 앱에서 동시에 사용할 수 없어요.

따라서, 모바일 Eufy 앱을 사용하여 별도의 이메일 주소로 새로운 "관리자" 계정을 만들어서 이 앱과 함께 사용하는 것을 추천드립니다.

사용법
- 이 앱을 홈이에 설치하세요.
- '기기 추가'로 이동하세요.
- 사용자 이름과 비밀번호를 입력하고 다음을 클릭하세요.
- 사용 가능한 기기가 나타납니다.
