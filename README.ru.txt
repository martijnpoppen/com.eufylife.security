УСТАРЕЛО — перейдите на «Anker Eufy»

Это приложение больше не развивается. Его заменяет Anker Eufy, которое поддерживает те же камеры,
видеозвонки, HomeBase, замки, клавиатуры и датчики, а также роботы-пылесосы, для которых требовался
Eufy Clean.

  https://homey.app/a/com.eufy/

Anker Eufy входит со своей собственной идентичностью устройства, поэтому второй аккаунт «админа»
больше не нужен, и ваш телефон не выйдет из приложения eufy.

Как перейти: установите Anker Eufy, добавьте устройства там, пересоберите свои Flow и удалите это
приложение, когда всё устроит. До тех пор оба приложения могут работать одновременно. Это приложение
продолжает работать, но новых устройств и функций не получит.


Инструкции по установке

Из-за особенностей работы закрытого API Eufy Security, комбинация email/пароль не может использоваться одновременно в мобильном приложении Eufy Security и приложении Homey.

Рекомендуется использовать мобильное приложение Eufy для создания вторичного "администраторского" аккаунта с отдельным адресом электронной почты и использовать его с этим приложением.

Использование
- Установите это приложение на ваш Homey.
- Перейдите к `добавить устройства`
- Введите ваше Имя пользователя и Пароль. Нажмите Далее
- Доступные устройства будут показаны
